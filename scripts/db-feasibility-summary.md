# 기업 정보 DB 구축 가능성 테스트 v2

## 실험 설정
- **Schema B (20)** — 쉬운 공개 정보 (회사명·설립년도·HQ·산업·CEO·경쟁사 등)
- **Schema A (30)** — Schema B + 어려운 10개 (정확한 valuation·ARR·MAU·피벗·한국 분석)
- 30개 회사 (인지도 3 tier)
- LLM: gemini-2.5-flash, anti-hallucination 프롬프트

## Tier별 평균 채움률

| 인지도 | Schema B (20) | Schema A (30) | 어려운 10개만 |
|---|---|---|---|
| 상위 (10) | 20.0/20 (100%) | 24.8/30 (83%) | 4.8/10 (48%) |
| 중위 (10) | 5.0/20 (25%) | 0.0/30 (0%) | 0.0/10 (0%) |
| 하위 (10) | 4.8/20 (24%) | 0.0/30 (0%) | 0.0/10 (0%) |

## 전체 평균
- Schema B: **50%**
- Schema A: **28%**
- 어려운 10개만: **16%**

## 핵심 발견
1. **쉬운 공개 정보 (Schema B)는 채울 수 있음** — 회사 기본 사실은 LLM이 알고 있음.
2. **어려운 분석/한국화/구체 수치 추가 (Schema A)는 급락** — 채움률 22%p 하락.
3. **인지도 낮은 회사는 양쪽 다 어려움** — 하위 그룹 Schema B도 24%.
4. **데이터 구축의 본질적 한계 정량 입증** — 양 늘리면 깊이 떨어지고, 깊이 늘리면 양 떨어짐.
