## 녹화 후 자막 입히기

### 방법 1 — 편집툴에서 import (가장 쉬움)
- CapCut / iMovie / DaVinci → 타임라인에 영상 올리고 `admin-demo-90s.srt` 드래그 → export

### 방법 2 — ffmpeg로 자막 구워넣기 (CLI)
```bash
cd /Users/tua3031/Desktop/2026/프로젝트/Widea_gemini_v2/docs

# 영상 파일명을 admin-demo-raw.mp4 라고 가정
ffmpeg -i admin-demo-raw.mp4 \
  -vf "subtitles=admin-demo-90s.srt:force_style='FontName=Pretendard,FontSize=22,PrimaryColour=&HFFFFFF&,BorderStyle=3,BackColour=&H80000000&,Outline=1,Shadow=0,MarginV=40'" \
  -c:a copy admin-demo-final.mp4
```
- 자막이 영상에 영구히 박혀서 어디서든 보입니다 (유튜브, 슬랙 미리보기 등)

### 방법 3 — 자막 별도 트랙 유지 (유튜브 권장)
- 유튜브 업로드 후 자막 → 파일 업로드 → `admin-demo-90s.srt`
- 시청자가 자막 ON/OFF 가능
